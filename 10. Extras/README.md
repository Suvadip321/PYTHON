# 10. Extras (The Open-Ended Sandbox)

This folder is deliberately left open-ended. 

As stated by the Pareto Principle (the 80/20 rule), folders `1` through `9` in this repository cover the **20% of the Python language that you will use 80% of the time** in daily software engineering. Those core folders represent the complete, non-negotiable foundation of the language.

### Why does this folder exist?
A programming language is a living, breathing ecosystem. There are always obscure built-in modules, advanced design patterns, and extremely niche syntactical tricks that you will eventually stumble across.

This folder serves as an open sandbox for **the remaining 80% of the language**. 

If you (or anyone contributing to this repository) discover a new, advanced, or niche concept that doesn't fit neatly into the core curriculum, it belongs here. 

### Examples of what could go here in the future:
*   Metaclasses and Abstract Syntax Trees (AST)
*   Niche built-in modules (`itertools`, `collections`, `collections.abc`)
*   Deep dives into Threading vs. Multiprocessing
*   C-Extensions and Python internals
*   Specific third-party library integrations

**Feel free to add anything to this folder as you continue your lifelong journey of learning Python!**
